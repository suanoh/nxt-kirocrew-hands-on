# 学科AI実習ミーティングのご案内

## 要約

学科の仲間と一緒にAIを実際に使ってみる実習ミーティングを開催します。定員は12名で、AI実習が初めての学生も参加できます。開催は2026年10月16日18時30分から20時まで、場所は学生会館ミーティング室です。参加費は無料で、個人のノートパソコンと充電器をご持参ください。会場ではWi-Fiを利用できます。英語および日本語の案内はミーティング情報を理解していただくために提供するものであり、翻訳された案内を読んだ場合でも、当日の案内も実習もすべて韓国語で進行します。参加を希望する学生は2026年10月14日18時までに学科グループチャットに名前を残してください。なお、すべての時刻は韓国時間(Asia/Seoul)です。

## 開催情報

| 項目 | 内容 |
| --- | --- |
| 日程 | 2026年10月16日 18:30～20:00(韓国時間 / Asia/Seoul) |
| 場所 | 学生会館ミーティング室 |
| 定員 | 12名 |
| 持ち物 | 個人のノートパソコンと充電器 |
| Wi-Fi | 会場で利用可能 |
| 参加費 | 無料 |
| 進行言語 | 案内・実習ともにすべて韓国語 |
| 参加対象 | AI実習が初めての学生も参加可能 |

## 申込方法

参加を希望する学生は、2026年10月14日18時(韓国時間)までに学科グループチャットに名前を残してください。別途の申込リンクは提供されません。日付と締切時刻を確認のうえ、案内された方法に従ってお申し込みください。
