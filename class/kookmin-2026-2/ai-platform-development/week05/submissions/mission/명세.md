## 3. 포함 기준

다음 중 하나에 해당하면 포함 후보로 판정한다.

1. 기준 시각(2026-09-14 09:00)에 **유효하거나 예정**인 안내·행사.
2. 접수·신청형 공지 중 **접수 마감이 기준 시각 이후**라서 아직 신청 가능한 것.
3. 재학생에게 유효한 **시설 운영 안내**(예: 도서관 운영시간 등).

## 4. 제외 기준

다음 중 하나에 해당하면 제외한다.

1. 기준 시각에 **이미 마감된 모집·접수**(신청 마감 시각이 기준 시각보다 앞선 경우).
2. **정정 공지로 대체된 원 공지**(원 공지의 일정이 취소·변경되어 정정본이 유효한 경우, 원 공지의 취소된 일정은 남기지 않는다).

## 5. 정정·병합 처리 방법

1. **최신 일시 적용:** 같은 행사 ID의 정정 공지가 있으면, 정정 공지에 기재된 **최신 일시**를 적용한다. 원 공지의 기존 일시가 정정본에서 취소된 경우 해당 일정은 남기지 않는다.
2. **동일 항목 병합:** 정정 공지에서 "장소·대상·신청 방식·준비물이 원 공지와 동일"하다고 밝힌 항목은 원 공지에서 값을 가져와 **하나의 항목으로 병합**한다.
3. **출처 ID 병기:** 병합한 항목에는 관련된 **모든 공지 ID를 출처에 함께 표기**한다(예: 원 공지 ID + 정정 공지 ID).
4. **취소 일정 제외:** 정정으로 취소된 원 일정은 브리핑에 남기지 않는다.
