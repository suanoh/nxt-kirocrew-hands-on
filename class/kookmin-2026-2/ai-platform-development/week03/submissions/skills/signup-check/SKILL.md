# 신청 현황 점검 (signup-check)

## 언제 쓰나
- 참가신청 CSV가 갱신되어(신청 변경·불참 전환·간식 응답) 간식 수량과 인원을 다시 세야 할 때.
- "주문 수량 확정"을 위한 집계에만 쓴다. 실제 주문/예약은 이 스킬의 범위가 아니다.

## 입력
- `참가신청.csv` — 열: `신청번호, 이름, 학년, 참가 여부, 간식 선택`
  - 신청번호 1개 = 1명.
  - `참가 여부`: `참가` 또는 `불참`.
  - `간식 선택`: `샌드위치` | `주먹밥` | `받지 않음` | (빈칸).

## 판단 규칙 (행사안내 기준)
1. **인원**: `참가 여부 == 참가`인 사람만 집계한다. `불참`은 인원·주문에서 모두 제외.
2. **간식 주문 (참가자만)**:
   - `샌드위치`/`주먹밥`은 1인당 1개로 센다.
   - `받지 않음`은 주문하지 않는다(0개).
   - `참가자의 빈칸`은 **미응답**이다. 임의로 메뉴를 정하지 말고 "확인 필요 명단"에 넣는다. 수량에는 포함하지 않는다.
   - `불참자의 빈칸`은 확인하지 않는다(무시).
3. **생수**: 간식 선택과 무관하게 참가 인원수만큼 준비한다.
4. **정원(기본 12명)**: 참가 인원이 정원을 넘으면 초과로 표시하고 운영진 확인이 필요하다고 알린다.

## 실행 절차
1. `python --version`으로 파이썬 실행을 확인한다.
   (이 환경 파이썬: `C:\Users\LOTTE\AppData\Local\Programs\Python\Python314\python.exe`)
2. 이 SKILL.md가 있는 폴더로 이동한 뒤 `scripts/tally_signups.py`를 CSV 경로를 인자로 주어 실행한다.
   예) `python scripts/tally_signups.py <참가신청.csv>`  (정원 변경 시 `--정원 8`)
3. 출력 JSON을 아래 "출력 구조"와 대조한다.
4. `미응답_확인필요` 명단이 비어 있지 않으면, 해당 인원에게 확인을 요청할 대상으로 따로 전달한다.
5. `정원초과`가 true면 운영진에게 추가 장소 확인을 알린다.

## 출력 구조 (항상 동일한 JSON)
```json
{
  "집계일시": "2026-09-16T11:43:00",
  "전체_신청수": 12,
  "참가_인원": 10,
  "불참_인원": 2,
  "정원": 12,
  "정원초과": false,
  "간식": { "샌드위치": 4, "주먹밥": 4, "받지_않음": 1 },
  "생수": 10,
  "미응답_확인필요": [
    { "신청번호": "A07", "이름": "한수빈", "사유": "간식 미선택" }
  ]
}
```

## 확인 사항
- 규칙에 없는 판단은 임의로 하지 않는다. 참가 여부·간식 값이 예상 밖이면 임의로 세지 말고 `미응답_확인필요`에 사유와 함께 담아 확인 대상으로 넘긴다.
- "수량 확정"과 "실제 주문 완료"는 구분한다. 이 스킬은 확정용 집계까지만 수행한다.
- CSV는 읽기만 하고 수정하지 않는다. 신청이 바뀌면 CSV만 고치고 다시 실행한다.
