# data-to-html

## 목적
빛담 행사(E04 등) 운영 자료를 한 화면에서 대조하기 위해, `documents/`의 규정·승인서·메모 MD와 `data/`의 CSV(참가신청·회계내역·구매계획)를 읽어 **문서별 요약 + CSV 핵심 표 + 규칙 기반 집계**를 담은 HTML 리포트 한 파일을 만든다.

## 입력
- MD 문서 여러 개 (documents 폴더)
- CSV 여러 개 (data 폴더): 참가신청·회계내역·구매계획

## 출력
- HTML 파일 한 개 (문서 요약 섹션 + CSV 핵심 표 + 집계 표)

## 집계 규칙 (원본 문서 근거)
- 참가 정원은 **장소 사용 승인서**를 따른다(홍보 정원·회의 요청으로 바꾸지 않는다). E04 = 160명(운영요원 별도).
- 물품 기본 인원은 **확정 인원**. 대기자는 별도 시나리오로만 계산한다.
- 회계 부호: 수입·환불입금은 +, 지출·환불지급은 -. 기초 잔액은 학교지원금 0 / 동아리회비 800,000.
- **재원별 현재 잔액** = 기초 + 수입 + 환불입금 - 지출 - 환불지급.
- **E04 재원별 순지출** = 지출 + 환불지급 - 환불입금 (수입 제외).
- 승인됐지만 미입금 금액은 가용 현금에 더하지 않는다(APPROVAL-FUND-04 잔여 500,000 제외).
- **구매계획**은 예정 수량 계산이며 회계 거래에 합산하지 않는다. 수량기준 '참가자' = 확정 인원 × 계수, '고정' = 계수. 예정비용 = 단가 × 수량.

## 실행
```
cd C:\Users\LOTTE\.kiro\crew\skills\data-to-html\scripts
python build_report.py --docs <documents 폴더> --data <data 폴더> --out <출력 HTML 경로>
```
스크립트는 CSV를 UTF-8로 직접 읽고, HTML도 UTF-8로 직접 저장한다(PowerShell 리다이렉트로 저장하지 않는다 — 한글 모지케 방지).

## 완료 조건
- 문서별 요약과 CSV 핵심 표를 **원본과 대조**한다.
- 저장한 HTML을 브라우저에서 직접 열어 확인한다.
- 원본 CSV는 보존한다(수정하지 않는다).
