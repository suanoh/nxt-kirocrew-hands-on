# club-budget-check

## 목적
운영 판단(정원·예산·대기자 전환)을 근거 있게 내리기 위해, `data/`의 CSV 3종을 `documents/`의 규정·승인서 근거로 집계한다. 결과는 항상 같은 기준으로 재현되며, 변경 승인서가 반영되면 정원·예산 판단이 자동으로 갱신된다.

## 입력
- `data/참가신청.csv` (신청_ID·행사_ID·신청상태·인화체험·식음료 …)
- `data/회계내역.csv` (거래·재원·유형·금액 …)
- `data/구매계획.csv` (항목·수량기준·계수·단가·예정재원)
- 정원은 CLI 인자 `--capacity`로 주입한다(기본 160, 변경 승인서 반영 시 180).

## 출력
- 표준출력 요약 + `--json` 지정 시 집계 JSON 파일

## 집계 규칙 (원본 문서 근거)
- 참가 정원 = 유효한 **장소 사용 승인서** 기준. 변경 승인서(CHANGE-SPACE-04)가 있으면 그 값(180). 홍보·회의만으로 바꾸지 않는다(RULE-02).
- 물품 기본 인원 = **확정 인원**. 대기자는 별도 시나리오로만 계산하며, 담당 승인 전 확정에 더하지 않는다(CLUB-01).
- 회계 부호: 수입·환불입금 +, 지출·환불지급 −. 기초 잔액 학교지원금 0 / 동아리회비 800,000(ACCOUNT-01).
- 재원별 현재 잔액 = 기초 + 수입 + 환불입금 − 지출 − 환불지급.
- E04 재원별 순지출 = 지출 + 환불지급 − 환불입금(수입 제외).
- 미입금 승인액(APPROVAL-FUND-04 잔여 500,000)은 가용 현금에 더하지 않는다.
- 구매계획은 예정 수량이며 회계 거래에 합산하지 않는다. '참가자' = 인원 × 계수, '고정' = 계수. 예정비용 = 단가 × 수량.
